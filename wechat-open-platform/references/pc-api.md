## 能力概览

| 能力 | 说明 |
|------|------|
| **拉起 PC 小程序** | 从网页中直接打开指定的小程序 |
| **分享 PC 小程序** | 将小程序分享到微信会话 |
| **运行 PC 小程序** | 在 PC 环境下运行小程序 |
| **微信分享** | 将网页内容分享到微信 |
| **获取 ticket** | 获取调用接口的一次性票据 |
| **获取 access_token** | 生成普通 access_token 用于鉴权 |

---

## 完整接口列表

### 服务端接口：获取 Ticket

```
POST https://api.weixin.qq.com/cgi-bin/pcopensdk/ticket?access_token=TOKEN
```

**请求参数：**

| 参数 | 是否必须 | 说明 |
|------|----------|------|
| ticket_type | 是 | 固定为 `"pcopensdk"` |

**返回参数：**

| 参数 | 说明 |
|------|------|
| ticket | 一次性票据，**5 分钟内有效，仅可调用一次** |

## 前置准备

1. 在微信开放平台注册开发者账号
2. 拥有一个**已审核通过**的网站应用
3. **配置业务域名**
4. **开通能力权限**（拉起 PC 小程序、分享 PC 小程序等）
5. 获得 AppID 和 AppSecret

## 前端 JS 接口

**引入方式：**

```html
<script src="https://res.wx.qq.com/connect/zh_CN/htmledition/js/wxopensdk.js"></script>
```

**调用示例（拉起小程序）：**

```javascript
function dosomething() {
  wxopensdk.launchMiniProgram({
    appid: "网站应用 appid",
    userName: "需拉起的小程序 userName（原始 ID）",
    path: "",
    ticket: "申请到的 ticket",
  });
}

// 等待 SDK 加载完成
if (wxopensdk.ready) {
  dosomething();
} else {
  wxopensdk.onReady = dosomething;
}
```

**可用接口：**

| 接口方法 | 功能 |
|----------|------|
| `wxopensdk.launchMiniProgram()` | 拉起 PC 小程序 |
| `wxopensdk.shareMiniProgram()` | 分享 PC 小程序 |
| `wxopensdk.runningMiniProgram()` | 运行 PC 小程序 |
| `wxopensdk.share()` | 微信分享 |

**返回值格式（Promise）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| errcode | number | 错误码 |
| errmsg | string | 错误说明 |
| actionId | string | 操作 ID，用于问题定位 |

## 错误码

### 通用错误码

| errcode | 描述 |
|---------|------|
| 0 | 正常触发操作 |
| 1 | 当前 SDK 运行环境不合法 |
| 2 | 网络错误 |
| 3 | ticket 错误 |
| 4 | 请求参数格式错误 |
| 5 | 后台异常 |
| 6 | 操作超时 |
| 7 | 未知错误 |
| 8 | 超过频率限制 |

### 业务错误码

| errcode | 描述 |
|---------|------|
| -11028 | 接口名错误 |
| -11029 | ticket 错误 |
| -11032 | **请求域名错误，请检查业务域名是否已在开放平台登记** |
| -11033 | **需要 HTTPS 页面** |
| -11034 | **当前接口无权限，请检查是否已在开放平台开通相关功能权限** |
| -11035 | 当前接口请求类型错误 |
| -11036 | 当前微信客户端版本不支持该接口 |

## 接口频率限制

所有接口在**用户维度**共享频率限制：

| 限制类型 | 阈值 |
|----------|------|
| 每秒调用 | **1 次** |
| 每分钟调用 | **5 次** |

## 技术要求与注意事项

| 项目 | 要求 |
|------|------|
| 页面协议 | **必须 HTTPS** |
| iframe 源 | 需允许 `https://open.weixin.qq.com` 源的 iframe |
| 代理配置 | **不能开启全局代理** |
| 进程签名 | 发起请求的进程必须有签名，否则会被拦截 |
| 运行环境 | 必须在 **WebView** 环境中，不支持纯原生应用 |
| JS 语法 | ES5 语法，理论上支持 ES5 及以上的 Web 环境 |
| 微信未登录 | SDK 通过 Scheme 拉起微信客户端，可能弹窗 |

## 特殊场景处理

### 微信未登录时

- SDK 会通过 **Scheme 拉起微信客户端**
- 在标准浏览器中可能出现**弹窗**，可能要求用户交互触发
- 可通过 `timeout` 参数控制尝试时间
- **`timeout=0`**：不拉起微信，初次连接失败即返回超时错误

### Chrome 142+ Local-Network-Access 限制

Chrome 142 及以上版本增加了本地网络访问权限提示：

| 用户状态 | 行为 |
|----------|------|
| 未授权 | 等待用户授权，不主动跳转微信 |
| 已拒绝 | 提示 PC OpenSDK 调用失败 |
| 已允许 | 正常进入调用流程 |

**适配建议：**

```javascript
navigator.permissions.query({ name: "local-network-access" });
```

### 常见问题

| 问题 | 答案 |
|------|------|
| 是否支持旧版本浏览器？ | ES5 语法，理论上支持 ES5 及以上 Web 环境 |
| 原生应用能否调用？ | **不能**，必须在 WebView 环境中运行 |
| 本地调试无法连接微信？ | 进程无签名会被拦截，需给应用增加签名 |
| 同时登录多个微信账号？ | 微信不支持同设备多登录，SDK 会随机连接其中一个实例 |
