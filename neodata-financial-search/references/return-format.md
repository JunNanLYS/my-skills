# NeoData Financial Search — 命令返回输出格式

> 本文档基于 29 个真实查询样本（覆盖 7 大类金融数据 + 9 个数据域，共 29 个接口）整理而成。
> 完整样本数据保存于 `D:/ai-skills/neodata-samples/`（4 个子目录：stock / index_board / fund_macro / forex_commodity，共 29 个 JSON 文件）。

---

## 一、命令总览

本技能**只有一个 query 命令**，通过 `--query` 参数传入自然语言查询，由服务端 LLM 路由到不同的数据接口：

```bash
python scripts/query.py --query "腾讯最新财报"
python scripts/query.py --query "贵州茅台股价" --data-type api
python scripts/query.py --query "黄金价格" --data-type doc
python scripts/query.py --save-token "<凭证>"   # 仅鉴权失败时使用
```

### 1.1 命令参数

| 参数 | 必填 | 取值 | 说明 |
|------|------|------|------|
| `--query` / `-q` | 是（除 `--save-token` 外） | 自然语言字符串 | 用户原始查询 |
| `--data-type` / `-d` | 否 | `all`（默认） / `api` / `doc` | `all`=API+文章；`api`=仅结构化；`doc`=仅文章 |
| `--token` / `-t` | 否 | JWT 或 tempToken | 优先级高于缓存文件（一般不用） |
| `--save-token` | 否 | 凭证字符串 | 将凭证写入 `~/.workbuddy/.neodata_token` |

### 1.2 请求体（脚本自动生成）

```json
{
  "query": "<用户查询>",
  "channel": "neodata",
  "sub_channel": "workbuddy",
  "data_type": "all|api|doc"
}
```

> `channel` 与 `sub_channel` 为固定值，脚本会自动填充。

## 二、统一响应结构

所有查询都返回如下顶层结构，**核心数据位于 `data.apiData.apiRecall[]`**：

```json
{
  "code": "200",
  "msg": "操作成功",
  "suc": true,
  "traceId": "392ddfa484498b5f8359db47d84122b0",
  "data": {
    "apiData": {
      "entity": [{ "code": "腾讯控股", "name": "00700.HK" }],
      "apiRecall": [
        {
          "tag": "股票数据库",
          "type": "股票实时行情",
          "desc": "股票实时行情",
          "content": "腾讯控股(代码:00700.HK)..."
        }
      ]
    },
    "seParams": {},
    "extraParams": {},
    "requestId": "74bc311eeb584b90924f0baa3c84350b"
  }
}
```

### 2.1 顶层字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | string | 状态码，`"200"`=成功；其余见第六章 |
| `msg` | string | 状态描述 |
| `suc` | boolean | 是否成功 |
| `traceId` | string | 链路追踪 ID |
| `data.apiData.entity` | array | 命中的标的列表（带市场后缀代码） |
| `data.apiData.apiRecall` | array | **核心 API 内容块列表** |
| `data.docData` | object | 文章召回结果（**实测 29 个样本中全部为空**） |
| `data.seParams` | object | 引擎参数（恒为空对象） |
| `data.extraParams` | object | 扩展参数（恒为空对象） |
| `data.requestId` | string | 服务端请求 ID |

### 2.2 entity 字段（命名与直觉相反）

```json
"entity": [
  { "code": "腾讯控股", "name": "00700.HK" },
  { "code": "贵州茅台", "name": "600519.SH" },
  { "code": "恒生指数", "name": "HSI.HK" }
]
```

| 字段 | 实际含义 |
|------|---------|
| `code` | **标的名称**（中文名） |
| `name` | **标的代码**（带市场后缀） |

> 板块、外汇、黄金等泛查询可能 `entity=[]`（空），实际数据全部在 `apiRecall.content` 中。

### 2.3 apiRecall 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `tag` | string | **数据域标签**（9 种：股票/基金/板块/宏观/外汇/期货数据/期货数据库/黄金/大盘数据库） |
| `type` | string | **接口名**（29 种中文长名） |
| `desc` | string | 类型描述（通常与 type 相同） |
| `content` | string | **核心数据**（Markdown 表格 / 自然语言 / 段落） |

## 六、错误码

### 6.1 业务错误码（响应 JSON）

| code | msg | 触发条件 | 处理 |
|------|-----|---------|------|
| `200` | 操作成功 | 请求成功 | 正常解析 |
| `1001` | 未命中意图，非财报query没法处理 | 查询语义不明确或不在技能能力范围 | 改写 query 措辞，使其更具体 |
| `1616039101` | [xxx]参数值不合法！ | 入参不合法 | 检查 query 字符串 |
| `1006` | 查询解析拒答 | 策略拦截、风险或不支持场景 | 改写 query，去掉敏感词 |
| `40101` | 鉴权错误 | 凭证验证失败 | 刷新凭证 |

### 6.2 脚本侧错误（脚本写到 stderr）

| stderr 输出 | 含义 | 处理 |
|------------|------|------|
| `TOKEN_MISSING` | 本地缓存文件不存在或为空 | 通过 WorkBuddy 调 `connect_cloud_service` |
| `TOKEN_EXPIRED` | JWT 已过期或 tempToken 超过 12h | 刷新凭证 |
| `AUTH_ERROR: HTTP 401` | 服务端拒绝当前凭证 | 刷新凭证 |
| `AUTH_ERROR: 服务返回鉴权错误` | 返回 JSON 中含 `40101` 或关键词命中 | 刷新凭证 |
| `REQUEST_FAILED` | 网络/超时异常 | 检查网络后重试 |
| `RESPONSE_PARSE_FAILED` | 响应不是合法 JSON | 重试 |

> 脚本对 TOKEN/AUTH 错误 `sys.exit(2)`，网络异常 `sys.exit(1)`。

## 八、使用建议

1. **始终用 `--data-type api`** 优先获取结构化数据；只有需要资讯/研报时才用 `all` 或 `doc`。
2. **`apiRecall[].content` 是字符串**，AI 解析时按"Markdown 表格 / 自然语言键值对 / 段落化文本 / 带头的表格"四类分别处理。
3. **`data.docData` 在 29 个样本中始终为空**，以 `apiData.apiRecall[].content` 为主输出。
4. **货币单位必须从 content 中提取并标注**，港股/美股切勿使用人民币符号。
5. **板块/概念股查询**：让 skill 自动路由；如需精确板块代码，可改用 westock-data 的 `sector --search` + `sector <代码>` 兜底。
6. **空 `apiRecall`** 出现于特定场景（如"宁德时代龙虎榜"），属于服务端当前未召回该接口的正常情况；不要判定为 skill 失败。
7. **跨期同比数据**可能受汇率影响，AI 解读时建议加注"注：同比数据可能受汇率波动影响"。
8. **失败重试**：脚本鉴权错误时只重试 1 次，仍失败则告知用户服务暂时不可用。
9. **单条 content 可能非常长**（如 `财务主要复合指标` 含多份财报拼接，`A股当日交易股票排行榜` 含 100+ 行个股），AI 解析时按需截取关键段。
